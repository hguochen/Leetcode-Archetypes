The Fundamental Directional Split

1 · Recognition Signals

✅ Strong Signals — Use Preorder
  • "Root-to-leaf path" in problem statement
  • "Does a path exist with sum X?" (boolean)
  • "Return all paths with sum X" (collection)
  • "Find all root-to-leaf paths"
  • "Sum of all root-to-leaf numbers"
  • "Construct a number from root to leaf"
  • "Maximum difference between node and ancestor"
❌ Anti-Signals — Don't Use Preorder
  • Path can start and end anywhere → Postorder Global+Local
  • Answer requires combining both subtrees at each node → Postorder
  • No state to pass downward → Postorder
  • Level-by-level processing → BFS / Level Order
⚠ Weak / Disguised Signals
  • "Path sum" — check root-to-leaf vs any-node-to-any-node
  • "Traverse with accumulator passed down" — could be preorder state
  • "Count nodes with even grandparent" — pass parent/grandparent down
  • "Max difference between ancestor and descendant" — pass min/max from root

2 · Cheat Sheet

Template Selector
Boolean existence?→ Pattern 1: hasPathSum — no backtracking

Top 3 Tricks
  • Leaf check ALWAYS: node.left==null && node.right==null
  • Backtrack only when state is mutable (List, StringBuilder)

Top 3 Pitfalls
  • Missing leaf check → false match at internal nodes
  • Adding path reference instead of copy to result
  • Forgetting backtrack → path grows without bound

3 · Traversal Order: Preorder vs Postorder

Preorder visits the root FIRST, then children. Postorder visits children FIRST, then root.

Mental Model — State Flowing Down

5 · The 4 Core Patterns

Pattern 1 — Boolean (Has Path Sum)

Yes/no question about whether a valid root-to-leaf path exists.

State: int remaining — primitive, passed by value → no backtracking

boolean hasPathSum(TreeNode root, int targetSum) {
    if (root == null) return false;
    // Leaf check — MANDATORY
    if (root.left == null && root.right == null)
        return root.val == targetSum;
    return hasPathSum(root.left,  targetSum - root.val)
        || hasPathSum(root.right, targetSum - root.val);
}
Why No Backtrack?

targetSum is an int. Java passes primitives by value. Each recursive call gets its own copy. Subtracting root.val only modifies that frame's local copy — nothing shared to undo.

Leaf Check Visualization

Pattern 2 — Collection (All Paths)

Collect every root-to-leaf path satisfying a condition.

State: List<Integer> path — mutable object, shared reference → backtracking required

void dfs(TreeNode node, int remaining,
         List<Integer> path, List<List<Integer>> result) {
    if (node == null) return;

    path.add(node.val);           // ← PREORDER: add before recursing

    if (node.left == null && node.right == null
            && node.val == remaining)
        result.add(new ArrayList<>(path)); // ← SNAPSHOT: copy

    dfs(node.left,  remaining - node.val, path, result);
    dfs(node.right, remaining - node.val, path, result);

    path.remove(path.size() - 1);  // ← BACKTRACK: undo after both
}

Pattern 3 — Encoding (Path as Number)

Build a value by incorporating each node's contribution on the way down. Check or sum at the leaf.

// #129 — Decimal encoding
int dfs(TreeNode node, int currentNum) {
    if (node == null) return 0;
    currentNum = currentNum * 10 + node.val; // shift + add
    if (node.left == null && node.right == null)
        return currentNum;  // leaf: complete number
    return dfs(node.left, currentNum) + dfs(node.right, currentNum);
}
// #1022 — Binary encoding (bit-shift)
int dfs(TreeNode node, int currentNum) {
    if (node == null) return 0;
    currentNum = (currentNum << 1) | node.val; // bit-shift + OR
    if (node.left == null && node.right == null)
        return currentNum;
    return dfs(node.left, currentNum) + dfs(node.right, currentNum);
}

Pattern 4 — State Propagation (Top-Down Constraint)

Pass ancestor's relevant state as parameters. Each node uses it and passes updated state to children. Decision can be made at any node, not just leaves.

// #1026 Max Difference: pass (min, max) from root
int maxAncestorDiff(TreeNode root) {
    return dfs(root, root.val, root.val);
}

int dfs(TreeNode node, int minSoFar, int maxSoFar) {
    if (node == null) return maxSoFar - minSoFar;
    minSoFar = Math.min(minSoFar, node.val);
    maxSoFar = Math.max(maxSoFar, node.val);
    int left  = dfs(node.left,  minSoFar, maxSoFar);
    int right = dfs(node.right, minSoFar, maxSoFar);
    return Math.max(left, right);
}
// #1315 Even Grandparent: pass parent + grandparent
int sumEvenGrandparent(TreeNode root) {
    return dfs(root, -1, -1);
}

int dfs(TreeNode node, int parent, int grandparent) {
    if (node == null) return 0;
    int sum = 0;
    if (grandparent % 2 == 0) sum += node.val; // use ancestor
    sum += dfs(node.left,  node.val, parent);
    sum += dfs(node.right, node.val, parent);
    return sum;
}
Key Difference from Patterns 1–3

The decision is NOT restricted to leaves. Any node can contribute to the answer based on its ancestor's value. All state parameters are primitives (int) → no backtracking needed.

6 · Flagship Problem — Path Sum II (#113)

Why This Is The Flagship

It requires all three core mechanics simultaneously: leaf check, snapshot, and backtracking. Mastering this problem means mastering the entire collection pattern.

class Solution {
    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        List<List<Integer>> result = new ArrayList<>();
        dfs(root, targetSum, new ArrayList<>(), result);
        return result;
    }

    private void dfs(TreeNode node, int remaining,
                     List<Integer> path, List<List<Integer>> result) {
        if (node == null) return;

        path.add(node.val);         // ①  PREORDER: add before recursing

        if (node.left == null && node.right == null && node.val == remaining) {
            result.add(new ArrayList<>(path)); // ②  SNAPSHOT: copy not reference
        }

        dfs(node.left,  remaining - node.val, path, result);
        dfs(node.right, remaining - node.val, path, result);

        path.remove(path.size() - 1); // ③  BACKTRACK: undo after both calls
    }
}
① Leaf Check

An internal node with val == remaining is NOT valid. Path must reach a leaf. Without this: every node with the right running sum would match.

② Snapshot

result.add(path) stores a reference. After backtracking, path is empty — result would contain empty lists. new ArrayList<>(path) captures the current state permanently.

③ Backtrack

After recursing both subtrees, this node must be removed. Without it, the parent's sibling subtree will see a stale prefix containing this node.

8 · Common Pitfalls

Pitfall 1 — Missing Leaf Check

❌ WRONG
if (remaining == 0) return true;
// matches any internal node
✅ CORRECT
if (node.left == null && node.right == null)
    return node.val == remaining;

Pitfall 2 — Path Reference vs Snapshot

❌ WRONG
result.add(path);
// adds reference → empty after backtrack
✅ CORRECT
result.add(new ArrayList<>(path));
// copy: frozen snapshot

Pitfall 3 — Missing Backtrack

❌ WRONG
path.add(node.val);
dfs(node.left, ...);
dfs(node.right, ...);
// forgot: path.remove(...)
✅ CORRECT
path.add(node.val);
dfs(node.left, ...);
dfs(node.right, ...);
path.remove(path.size() - 1);

Pitfall 4 — Null Check Order

❌ WRONG — NullPointerException
if (node.left == null && node.right == null)
if (node == null) return false;
✅ CORRECT — null guard first
if (node == null) return false;
if (node.left == null && node.right == null)

10 · Decision Framework

Input is a binary tree? └── YES ├── Path starts at root? → Path Tracking (Archetype 8) │ ├── Path ends at leaf? │ │ ├── YES — root-to-leaf path │ │ │ ├── Boolean output? → Pattern 1 (hasPathSum, no backtrack) │ │ │ ├── Collect all paths? → Pattern 2 (backtrack + snapshot) │ │ │ └── Aggregate value (sum of numbers)? → Pattern 3 (encoding, primitive) │ │ └── NO — path from any node → Postorder Global+Local (Archetype 7) │ └── Ancestor state needed at each node? → Pattern 4 (state propagation) │ ├── Need info from both subtrees first? → Postorder DFS (Archetype 7) └── Need level-by-level? → BFS / Level Order (Archetype 9)

Step-by-Step Decision

Step 1

Does the path start at root? → YES → Path Tracking

Step 2

Does it end at a leaf? → YES → root-to-leaf; NO → Postorder

Step 3

Output type: bool → P1 / collect → P2 / aggregate → P3 / ancestor state → P4

Step 4

State mutable? YES → backtrack required. NO → no backtrack.

12 · Drill Section — Mastery Check

Verbal Drill (2 minutes)

  1. Preorder DFS solves tree problems where state flows down from parent to child
  2. The two core variants: boolean (no backtrack, primitive state) and collection (backtrack, mutable state)
  3. Backtracking: add → snapshot if match → recurse left → recurse right → remove
  4. The leaf check is mandatory for root-to-leaf — internal nodes are false positives
  5. Encoding (Pattern 3): multiply/shift on way down, aggregate at leaf, no backtrack needed

Primitive Speed Test

Write each from scratch with no reference. Target: < 3 min each, zero bugs.
